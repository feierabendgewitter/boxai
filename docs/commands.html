Commands

Everything the CLI can do.

CommandPurpose
boxai upCreate worktrees and sandbox, start the agent; running again resumes
boxai scanList repos under a folder
boxai listWorkspaces and sandbox status
boxai attach <name>Restart the agent
boxai stop <name>Stop the sandbox
boxai rm <name>Remove sandbox, worktrees, kit and state; branches are kept without --delete-branches
boxai doctorCheck prerequisites; --network checks profile allowances against the sbx policy
boxai initWrite boxai.yaml and secrets.example.yaml
boxai agent-helpPrint a guide for AI agents that operate boxai

Key options of up

OptionMeaning
--nameWorkspace name
--repoAdd a repo, can be repeated
--agentclaude, copilot, antigravity
--profileKommagetrennte Stack profiles
--configLoad configuration from boxai.yaml
--dry-runOnly show commands

Run boxai <command> --help to see all options.

For AI agents

boxai agent-help prints a guide that lets an AI agent operate boxai itself.
