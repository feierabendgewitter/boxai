Kommandos

Alles, was die CLI kann.

KommandoZweck
boxai upWorktrees und Sandbox anlegen, Agent starten; ein erneuter Lauf setzt fort
boxai scanRepos unter einem Ordner auflisten
boxai listWorkspaces und Sandbox-Status
boxai attach <name>Agent erneut starten
boxai stop <name>Sandbox anhalten
boxai rm <name>Sandbox, Worktrees, Kit und State entfernen; Branches bleiben ohne --delete-branches
boxai doctorVoraussetzungen prüfen; --network prüft Profil-Freigaben gegen die sbx-Policy
boxai initboxai.yaml und secrets.example.yaml schreiben
boxai agent-helpAnleitung für KI-Agenten ausgeben, die boxai bedienen

Wichtige Optionen von up

OptionBedeutung
--nameName des Workspaces
--repoRepo hinzufügen, mehrfach nutzbar
--agentclaude, copilot, antigravity
--profileKommagetrennte Stack-Profile
--configKonfiguration aus boxai.yaml laden
--dry-runKommandos nur anzeigen

Mit boxai <kommando> --help siehst du alle Optionen.

Für KI-Agenten

boxai agent-help gibt eine Anleitung aus, mit der ein KI-Agent boxai selbst bedienen kann.

boxai · Quellcode auf GitHub · Ein Agent, mehrere Repos, sicher in einer Sandbox.
