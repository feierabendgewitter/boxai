Installation

Ein Binary, ein paar Voraussetzungen.

Voraussetzungen

  • macOS oder Linux, jeweils mit git
  • sbx ab Version 0.51
  • Docker, nur für make images und --dockerfile

1. sbx installieren

brew install docker/tap/sbx
sbx login

Mehr dazu in der Docker-Sandboxes-Dokumentation.

2. boxai installieren

Mit Go

go install github.com/feierabendgewitter/boxai/cmd/boxai@latest

Aus einem Release

Fertige Binaries gibt es unter Releases. Entpacken und in den PATH legen.

Aus dem Quellcode

git clone https://github.com/feierabendgewitter/boxai.git
cd boxai
make build        # erzeugt bin/boxai

3. Installation prüfen

boxai doctor

boxai doctor prüft die Voraussetzungen. Mit --network vergleicht es zusätzlich die Freigaben deiner Profile mit der sbx-Policy.

Images (optional)

Ohne eigene Images startet der Agent mit seinem Standard-Image, und boxai weist darauf hin, welche Tools dort fehlen. Die Images mit den Profilen baust du aus dem Repository:

make images
