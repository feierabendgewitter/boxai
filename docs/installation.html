Installation

One binary, a few prerequisites.

Prerequisites

  • macOS or Linux, each with git
  • sbx version 0.51 or later
  • Docker, only for make images and --dockerfile

1. Install sbx

brew install docker/tap/sbx
sbx login

More in the Docker Sandboxes documentation.

2. Install boxai

With Go

go install github.com/feierabendgewitter/boxai/cmd/boxai@latest

From a release

Prebuilt binaries are available under Releases. Unpack them and put them on your PATH.

From source

git clone https://github.com/feierabendgewitter/boxai.git
cd boxai
make build        # produces bin/boxai

3. Verify the installation

boxai doctor

boxai doctor checks the prerequisites. With --network it also compares your profiles' allowances with the sbx policy.

Images (optional)

Without custom images, the agent starts with its default image, and boxai points out which tools are missing there. You build the images with the profiles from the repository:

make images
