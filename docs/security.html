Security

What boxai protects and where the limits are.

Isolation

The agent runs in a Docker sandbox and only has access to the mounted worktrees and allowed hosts. Network rules and secrets are set per sandbox; the global policy stays unchanged.

Secrets

  • The sandbox only sees placeholders; the sbx proxy replaces them in request headers to allowed hosts.
  • Secret values never appear in logs, state files, kits or command lines. They go to sbx via stdin and are masked in output.
  • Exception: secrets.mode: env passes plaintext into the sandbox and warns when doing so.

Limits

Important: Through the mount of <repo>/.git, the agent can modify objects and branches of your main repos. This is necessary for worktrees to work inside the sandbox. Back up important branches and review results before you push them.

boxai rm only removes branches with --delete-branches.
