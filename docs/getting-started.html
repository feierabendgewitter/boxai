Erste Schritte

Vom Projektordner zur laufenden Sandbox.

Interaktiv starten

Wechsle in den Ordner, der deine Repos enthält, und starte boxai up. Es fragt Name, Repos und Agent ab.

cd ~/projekte
boxai up

Nicht-interaktiv

boxai up --name shop \
  --repo backend --repo frontend \
  --agent claude --profile kotlin-spring,react

Mit Konfigurationsdatei

Für wiederholbare Setups legst du dir eine boxai.yaml an. boxai init schreibt eine Vorlage samt secrets.example.yaml.

boxai init
boxai up --config boxai.yaml

Alle Optionen stehen unter Konfiguration.

Erst ansehen, dann ausführen

Mit --dry-run gibt boxai alle git- und sbx-Kommandos aus, ohne sie auszuführen.

boxai up --config boxai.yaml --dry-run

Im Alltag

boxai list              # Workspaces und Sandbox-Status
boxai attach shop       # Agent erneut starten
boxai stop shop         # Sandbox anhalten
boxai rm shop           # alles aufräumen (Branches bleiben)

Eine Übersicht aller Kommandos findest du unter Kommandos.

Hinweis: Der Agent kann über den Mount von <repo>/.git Objekte und Branches deiner Haupt-Repos verändern. Lies dazu Sicherheit.
