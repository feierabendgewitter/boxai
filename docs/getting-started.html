Getting started

From project folder to running sandbox.

Start interactively

Change into the folder that contains your repos and run boxai up. It asks for the name, repos and agent.

cd ~/projects
boxai up

Non-interactive

boxai up --name shop \
  --repo backend --repo frontend \
  --agent claude --profile kotlin-spring,react

With a config file

For repeatable setups, create a boxai.yaml. boxai init writes a template along with secrets.example.yaml.

boxai init
boxai up --config boxai.yaml

Alle Optionen stehen unter Configuration.

Look first, then run

With --dry-run, boxai prints all git and sbx commands without executing them.

boxai up --config boxai.yaml --dry-run

Day to day

boxai list              # Workspaces and sandbox status
boxai attach shop       # Restart the agent
boxai stop shop         # Stop the sandbox
boxai rm shop           # clean everything up (branches stay)

An overview of all commands is on the Commands page.

Note: Through the mount of <repo>/.git, the agent can modify objects and branches of your main repos. See Security.
