Docker Sandbox · Git Worktrees · KI-Agenten

Ein Agent. Mehrere Repos.
Vom Host isoliert.

boxai bündelt mehrere Git-Repos als Worktrees zu einem Workspace und startet ihn in einer Docker Sandbox mit Claude Code, GitHub Copilot CLI oder Google Antigravity.

Erste SchritteInstallation
$ cd ~/projekte
$ boxai up --name shop --repo backend --repo frontend \
      --agent claude --profile kotlin-spring,react
✓ Worktrees angelegt   backend, frontend @ feature/x
✓ Kit erzeugt          Agent- und Skill-Dateien aus den Repos
✓ Sandbox gestartet    boxai-shop · claude

Was boxai kann

Repo-übergreifend arbeiten

Backend, Frontend und geteilte Bibliotheken liegen als Worktrees nebeneinander im selben Workspace. Der Agent sieht den ganzen Zusammenhang, deine Checkouts bleiben unberührt.

Isolierte Sandbox

Der Agent läuft in einer Docker Sandbox (sbx) und nicht direkt auf deinem Rechner. Netzwerkfreigaben sind pro Sandbox konfiguriert.

Drei Agenten

Claude Code, GitHub Copilot CLI und (experimentell) Google Antigravity. Ein Workspace, frei wählbarer Agent.

Stack-Profile

Die Profile kotlin-spring und react bringen passende Images und Konfiguration mit und sind kombinierbar.

Secrets ohne Klartext

Die Sandbox sieht nur Platzhalter. Der sbx-Proxy setzt den echten Wert in Requests an erlaubte Hosts ein. Werte landen weder in Logs noch im State.

Wiederaufnehmbar

Ein erneuter boxai up setzt fort, wo er aufgehört hat. Mit --dry-run siehst du vorab jedes git- und sbx-Kommando.

So funktioniert es

  1. Scannenboxai findet die Git-Repos unter deinem Projektordner.
  2. WorktreesPro Repo entsteht ein Worktree auf einem gemeinsamen Feature-Branch.
  3. KitAgent- und Skill-Dateien, Profile und Secrets werden zu einem Kit gebündelt.
  4. SandboxDie Sandbox startet, und der Agent legt los.

Bereit?

Ein statisches Go-Binary für Linux und macOS. Installiert in einer Minute.
