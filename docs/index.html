Docker Sandbox · Git Worktrees · AI Agents

One agent. Multiple repos.
Isolated from the host.

boxai bundles multiple Git repos as worktrees into one workspace and launches it in a Docker sandbox with Claude Code, GitHub Copilot CLI or Google Antigravity.

Getting startedInstallation
$ cd ~/projects
$ boxai up --name shop --repo backend --repo frontend \
      --agent claude --profile kotlin-spring,react
✓ Worktrees created     backend, frontend @ feature/x
✓ Kit generated         agent and skill files from the repos
✓ Sandbox started       boxai-shop · claude

What boxai can do

Work across repos

Backend, frontend and shared libraries sit side by side as worktrees in the same workspace. The agent sees the whole picture, and your checkouts stay untouched.

Isolated sandbox

The agent runs in a Docker sandbox (sbx) and not directly on your machine. Network allowances are configured per sandbox.

Three agents

Claude Code, GitHub Copilot CLI and (experimental) Google Antigravity. One workspace, your choice of agent.

Stack profiles

The kotlin-spring and react profiles ship matching images and configuration and can be combined.

Secrets without plaintext

The sandbox only sees placeholders. The sbx proxy inserts the real value into requests to allowed hosts. Values end up in neither logs nor state.

Resumable

Running boxai up again picks up where it left off. With --dry-run you see every git and sbx command beforehand.

How it works

  1. Scanboxai finds the Git repos under your project folder.
  2. WorktreesEach repo gets a worktree on a shared feature branch.
  3. KitAgent and skill files, profiles and secrets are bundled into a kit.
  4. SandboxThe sandbox starts and the agent gets to work.
